# UNFLECT — Non-Branded SEO Keyword-to-Page Mapping

This document maps UNFLECT's core pages to their designated primary and secondary search intents, audience profiles, and internal link architecture.

## Strategy & Principles
- **Intent Separation**: Every page serves a single distinct primary search intent to prevent keyword cannibalization.
- **Truthful Alignment**: Keywords are only targeted where they represent capabilities UNFLECT actually delivers (custom web apps, internal tools, dashboards, integrations, workflow automation).
- **No Artificial Geo-Stuffing**: UNFLECT is positioned as a remote-first custom software studio founded in India, working with clients globally and across time zones.

---

## Page-by-Page Mapping

### 1. Homepage (`/`)
- **Primary Search Intent**: Discovery of a reliable custom software development studio/company.
- **Main Keyword Theme**: `Custom software development company`
- **Secondary Topics**: `Custom business software`, `Bespoke software development`, `Software development studio`, `Custom software development for small businesses`
- **Intended Audience**: Founders, CEOs, Operations Directors, and Business Leaders seeking an engineering partner to build bespoke software rather than hiring an oversized agency.
- **Title Tag**: `UNFLECT · Custom Software Development Company`
- **Meta Description**: `UNFLECT is a custom software development company. We engineer bespoke web applications, internal business tools, operations platforms, and workflow integrations.`
